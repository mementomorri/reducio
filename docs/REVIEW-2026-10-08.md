## Inconsistencies and noise

- **Diagnostic flood in `deduplicate`.** There is one `unsupported_scope` per method or nested
  function and one `dependencies` per skipped function.
  - On reducio's own 42 files, a "0 groups" result prints 241 lines, twice: stdout preview and stderr.
  - On stdlib it is 51,708 diagnostics, all stored in the session JSON (54 KB for reducio).
  - Emit one summary per file (or per run) with counts, keeping details for `-v`. This also cuts lines.
- **Dedup barely sees real code.** The dependency filter (any reference to a module-level name
  or import) skips 85 % of stdlib top-level functions, leaving 1,512 of about 10,400. reducio's
  own code yields 0 groups.
  - This is right for `--rewrite`, which moves the function.
  - It is stricter than needed for suggestion mode, which only proposes a copy for review.
  - Option: allow dependencies in suggest mode and list the needed imports in the description.
- **`cli._has_changes(plan, cfg=None, path=None, …)`** has defaults nobody uses (one caller
  passes every argument). Drop the defaults, or fold it into `_review_and_apply`.
- **Model disclosure host.** `_prepare_llm` shows `api.anthropic.com` when `llm_api` is unset
  but `model` is set, before the client rejects the config. Cosmetic.
- **Loopback by name only** (`127.0.0.2` counts as remote) is a known, commented shortcut.
